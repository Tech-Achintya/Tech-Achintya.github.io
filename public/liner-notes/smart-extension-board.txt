The Smart Extension Board is an IoT-based system designed to remotely control electrical appliances using a NodeMCU (ESP8266) microcontroller. The device is connected to a relay module that acts as a switch to turn appliances ON or OFF. It uses Wi-Fi connectivity to communicate with a cloud platform, enabling users to control devices through a web or mobile interface in real time. The system allows multiple appliances to be managed efficiently, improving convenience and energy usage. The backend communication is handled through IoT cloud services, where commands are sent and executed instantly by the NodeMCU. The project demonstrates the practical integration of embedded systems, networking, and automation.
